# Релиз — что вошло в каждую версию

Как это читать: **«Релиз»** — подробная запись уровня диалога: что сделано и что это
значит. В git от релиза остаётся только сжатая строка коммита и файл `RELEASE_NOTES.md`
за последнюю версию — этот таб и есть то место, где подробность сохраняется.

Записи собраны по истории репозитория: теги, даты и сообщения коммитов. Чем старше
релиз, тем короче запись — за ранние месяцы подробных разборов в диалогах уже нет, а
придумывать их задним числом нельзя. Свежие релизы описаны полнее.

Уровень релиза: `patch` — исправление, `minor` — новая возможность, `major` — ломающее
изменение. Нумерация: `2.28.0` — мажор 2, минор 28, патч 0. Уровень взят у самих релизов:
для версий 2.x он объявлен в коммите перед выкладкой, для релизов 1.0.x маркеров ещё не
было — там он считается по тому, какая цифра версии выросла.
