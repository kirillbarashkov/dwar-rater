# Реестр техдолга и согласованные планы

Правило проекта: долг **не чинится попутно** — он попадает сюда, а объём назначает
владелец проекта. Здесь же — планы фич, которые согласованы, но ещё не начаты: чтобы
они не жили только в переписке.

Обновлено: 2026-10-18.

> Канонический источник теперь этот файл.

## Согласованные планы, к которым не приступали

### AI-советник для трека улучшений

Самый крупный задел: план на фазы 0–9 (`development-roadmap/ai-advisor-improvement-track-v1.2.md`),
стек решён — RAG внутри Flask без отдельного сервиса (сценарий D), эмбеддер bge-m3, pgvector,
сборщик промптов, наблюдаемость, bootstrap 30–50 выверенных правил. **Старт: после чистки
техдолга и типизированных контрактов.**

### Типизированные контракты сервисов

`spec.py` в фичах вместо словарей «на честном слове» (пункт 2.1 из design-roadmap).
Делать **до** AI-советника: у эндпоинтов советника должны быть контракты, а не вывод типов
из фактического ответа.

### Мелкое, но согласованное ранее

- **Слепок при закрытии профиля.** Сейчас `closed_profiles.snapshot_id` пуст: слепок не
  снимается, пока персонаж открыт, поэтому после закрытия восстанавливать данные неоткуда.
  Идея: снимать слепок автоматически при успешном анализе.
- **Контент «О проекте» в базе с правкой из админки.** Осознанно оставлено на потом:
  сейчас тексты живут markdown-файлами в репозитории и приезжают с релизом (правки
  видны в истории git). Вариант «править без релиза» потребует модели, CRUD и прав —
  отдельный этап, если понадобится.
